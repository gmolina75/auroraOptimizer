# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto se adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-09-28

### Añadido
- Scripts de optimización para Linux, Windows y macOS
- Instalador multiplataforma automático
- Detección inteligente de SSD/HDD
- Limpieza de memoria, cachés y archivos temporales
- Defragmentación automática para HDD
- TRIM automático para SSD
- Sistema de logging con rotación automática
- Configuración personalizable vía `aurora.conf`
- Notificaciones del sistema operativo
- **Notificaciones por correo electrónico**
- **Notificaciones por Telegram**
- **Detección de reinicio del equipo**

### Características
- ✅ Multiplataforma (Linux, Windows, macOS)
- ✅ Detección automática de tipo de disco
- ✅ Ejecución automática al inicio del sistema
- ✅ Logs detallados con rotación
- ✅ Configuración flexible
- ✅ Notificaciones por correo y Telegram
